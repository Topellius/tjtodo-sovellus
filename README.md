# tjtodo-sovellus

Yksinkertainen TODO-sovellus, joka on toteutettu Reactilla ja Next.js:llä. Sovelluksessa voi lisätä, muokata, merkitä valmiiksi ja poistaa tehtäviä. Tehtävät tallennetaan selaimen `localStorage`-muistiin, joten ne säilyvät myös sivun päivityksen jälkeen.

## Ominaisuudet

- Lisää uusia tehtäviä
- Merkitse tehtävä valmiiksi
- Muokkaa olemassa olevaa tehtävää
- Poista yksittäinen tehtävä
- Poista kaikki valmiit tehtävät
- Tyhjennä koko TODO-lista
- Näytä valmiiden tehtävien määrä
- Säilytä tehtävät selaimen `localStorage`-muistissa
- Responsiivinen käyttöliittymä

## Teknologiat

- Next.js 16
- React
- TypeScript
- Tailwind CSS
- ESLint
- Browser `localStorage`
